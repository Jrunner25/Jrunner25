## How I build

- **Guardrails in code, not prompts.** Token caps, budgets, run-rate limits and loop detection on every agent.
- **A human approves anything outward-facing.** Agents draft; I sign off.
- **Deterministic where it matters.** LLMs read and write text; plain code decides facts.
- **Tested.** The modules I publish ship with their test suites.
